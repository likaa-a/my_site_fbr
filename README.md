# Театр «Третий звонок»

Учебный многостраничный сайт современного театра. Посетитель может посмотреть афишу, открыть страницу спектакля, прочитать отзывы и ответы на вопросы, а затем заполнить форму бронирования билетов.

## Практическая работа №10

Тема: применение компонентов Bootstrap при создании каталога, страницы товара и формы заказа. В предметной области театра каталог — это афиша, товар — спектакль, заказ — бронирование билетов.

Использованы HTML5, CSS3, Bootstrap 5.3.8 через CDN и JavaScript. Собственные стили находятся в `css/custom.css` и подключаются после Bootstrap.

## Страницы

- `index.html` — главная страница театра;
- `catalog.html` — афиша с сеткой карточек спектаклей и модальным окном быстрого заказа;
- `product.html` — подробная страница спектакля с хлебными крошками, таблицей и аккордеоном;
- `order.html` — форма бронирования билетов;
- `about.html` — информация о театре;
- `reviews.html` — отзывы посетителей;
- `faq.html` — часто задаваемые вопросы;
- `afisha.html` и `booking.html` — совместимые перенаправления со старых адресов.

## Выполненные компоненты Bootstrap

- единая адаптивная навигация `navbar-expand-lg` с мобильным переключателем, выпадающим меню и активным пунктом;

## Запуск

Можно открыть `index.html` напрямую либо запустить локальный сервер из корня проекта:

```powershell
python -m http.server 8000
```

После запуска сайт доступен по адресу `http://127.0.0.1:8000/`.

Формы работают в демонстрационном режиме и не отправляют персональные данные на сервер. Названия спектаклей, даты, адрес, контакты и отзывы являются учебным контентом.
