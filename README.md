# Театр «Третий звонок»

Учебный многостраничный сайт современного театра. Посетитель может посмотреть афишу, открыть подробную карточку спектакля, прочитать отзывы и ответы на вопросы, а затем заполнить форму бронирования билетов.

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

- Группа: **указать перед сдачей в СДО**.
- Репозиторий: <https://github.com/likaa-a/my_site_fbr>

В предметной области театра каталог — это афиша, товар — спектакль, заказ — бронирование билетов.

## Используемый фреймворк

Bootstrap 5.3.8 подключён локально. Проект не зависит от CDN для загрузки стилей и интерактивных компонентов Bootstrap.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`;
- `css/custom.css`, подключённый после Bootstrap.

## Страницы

- `index.html` — главная страница с hero-блоком, преимуществами и популярными спектаклями;
- `catalog.html` — афиша с Bootstrap-сеткой, карточками и модальным окном быстрой заявки;
- `product.html` — карточка спектакля с описанием, ценой, характеристиками и аккордеоном;
- `order.html` — адаптивная форма бронирования билетов;
- `about.html` — раздел «Наша история» с рассказом о развитии театра и фотогалереей;
- `reviews.html` — отзывы посетителей с оценками;
- `faq.html` — часто задаваемые вопросы;
- `afisha.html` и `booking.html` — перенаправления со старых адресов.

## Реализованные Bootstrap-компоненты

- `container-fluid`, `row`, `col-*`, `g-*` — адаптивная сетка;
- `navbar`, `navbar-expand-lg`, `collapse` — навигация и мобильное меню;
- `card`, `btn`, `badge`, `alert` — карточки и элементы интерфейса;
- `modal` — быстрая заявка из каталога;
- `form-control`, `form-select`, `input-group`, `form-check` — поля формы;
- `breadcrumb`, `table-responsive`, `table` — страница спектакля;
- `accordion` — дополнительный интерактивный компонент.

Bootstrap JS Bundle обеспечивает работу мобильной навигации, модального окна, карусели и аккордеона.

## Как проверить проект

Запустите локальный сервер из корня проекта:

```powershell
python -m http.server 8000
```

Откройте <http://127.0.0.1:8000/> и проверьте:

1. переходы по пунктам навигации;
2. карточки и адаптивную сетку афиши;
3. открытие и закрытие модального окна быстрой заявки;
4. передачу спектакля на `product.html` и `order.html`;
5. проверку обязательных полей формы;
6. раскрытие аккордеона;
7. отображение на ширинах 375, 768, 1024 и 1440 px.

Формы работают в демонстрационном режиме и не отправляют персональные данные на сервер. Названия спектаклей, даты, адрес, контакты и отзывы являются учебным контентом.
