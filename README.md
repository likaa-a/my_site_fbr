# Театр «Третий звонок»

Учебный одностраничный сайт современного театра. Посетитель может познакомиться с афишей, посмотреть сведения о спектаклях, прочитать отзывы и ответы на частые вопросы, а затем подготовить заявку на бронирование билетов.

Проект выполнен для контрольной работы №2 по теме «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Используемые технологии

- HTML5;
- CSS3;
- Bootstrap 5.3.3 через CDN;
- JavaScript;
- собственные стили в `css/custom.css`.

## Структура проекта

```text
my_site_fbr/

├── css/

│   ├── last-guest.png

├── README.md

```

## Выполненные требования раздела 7

- создана главная страница `index.html`;
- подключены Bootstrap CSS и Bootstrap JS Bundle через CDN;
- подключён собственный файл `css/custom.css` после Bootstrap;
- создана адаптивная шапка с навигацией;
- hero-блок построен на Bootstrap-сетке;
- преимущества оформлены через `row` и адаптивные `col-*`;
- афиша оформлена карточками в сетке `col-12 col-md-6 col-lg-4`;
- добавлен подвал;
- подготовлен README;
- разработка ведётся в отдельной Git-ветке `feature/theatre-homepage`.

## Дополнительные возможности

- модальное окно с описанием спектакля;
- отзывы зрителей в Bootstrap Carousel;
- часто задаваемые вопросы в Bootstrap Accordion;
- форма бронирования с клиентской проверкой;
- автоматический выбор спектакля в форме;
- анимации с поддержкой `prefers-reduced-motion`;
- доступные подписи полей, альтернативные тексты изображений и ссылка пропуска навигации.

## Запуск

Откройте `index.html` в браузере. Для корректной загрузки Bootstrap и шрифта требуется подключение к интернету.

Форма работает в демонстрационном режиме и не отправляет данные на сервер.

## Учебный контент

Названия спектаклей, даты, адрес, контакты и отзывы являются демонстрационными и должны быть заменены реальными данными перед публикацией. Изображения созданы специально для этого учебного проекта с помощью генератора изображений OpenAI.
